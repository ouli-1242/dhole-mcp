向量数据库主要用来存和搜“向量”（把文字、图片、语音转成数字后的表示），核心是按语义相似度快速找内容，常见产品有 ‌Milvus、Chroma、Qdrant、Pinecone、pgvector‌ 等，不同产品在规模、部署、运维成本和查询能力上差别明显。‌‌1百度百科

主流向量数据库有什么区别

  1. ‌Milvus‌：开源、分布式，适合大规模生产环境，能支撑亿级向量和高并发检索，但部署运维相对复杂。
  2. ‌Chroma‌：轻量、易上手，适合原型开发、小项目或本地实验，数据规模较小时用起来很方便。
  3. ‌Qdrant‌：Rust 编写，过滤能力强，支持复杂条件查询，中小团队生产场景较常用。
  4. ‌Pinecone‌：全托管云服务，开箱即用，省运维，但按使用量付费，长期成本可能较高。
  5. ‌pgvector‌：PostgreSQL 插件，如果你已经用 PostgreSQL，可直接在库里加向量检索能力，适合数据规模不太大、又需要和业务表联合查询的场景。‌‌

怎么根据场景选

  • ‌纯向量检索、数据量很大‌：优先考虑 ‌Milvus‌ 或 ‌腾讯云向量数据库‌ 这类独立向量数据库，检索延迟和吞吐表现更好。
  • ‌向量和业务表经常一起查‌：例如查相似文档时还要按用户权限、订单状态过滤，‌pgvector‌ 或 ‌KingbaseES‌ 等融合型方案更顺手，一条 SQL 就能完成。
  • ‌刚起步、快速验证‌：用 ‌Chroma‌ 或 ‌Qdrant‌，上手快、成本低，适合小规模实验。
  • ‌不想自己运维、追求省心‌：可选 ‌Pinecone‌ 或云托管服务，但要注意长期使用成本。‌‌

选型时重点看什么

  • ‌数据规模‌：百万级向量，多数方案都能满足；亿级以上，独立分布式数据库优势更明显。
  • ‌查询方式‌：是否需要同时做关键词匹配和向量语义检索，部分产品支持混合搜索，部分需额外搭配。
  • ‌运维成本‌：自建开源方案长期成本可能更低，但需要投入运维人力；托管服务花钱但省事。
  • ‌合规与环境‌：如果在信创或国产化环境中，可优先考虑国产数据库及其向量扩展能力。‌‌
