## 十张画像卡（封存，执行前不改）

### P01 温旖 · 内容创作者 L2
- 情境：在家赶下周选题，中等急。
- 真实目标（对 AI 残缺）：「帮我攒个可复用的选题库，明天接着用」。
- 验收：跨会话二访时昨天存的页能找回来；同一页两次抓取不出现两行打架（R02-007 回归）。
- 耐心：愿等 15s/步；第 3 次找不到就放弃。
- 不告诉 AI：昨天具体存了哪些 URL（考察召回还是瞎猜）。
- 变卦点：中途改口「先只要 3 篇」。
- 主攻：web_search → web_read →（跨会话）web_recall；绑定回归 R02-007。

### P02 沙青 · 技术写作 L3（缺陷猎手）
- 情境：给某开源项目重写文档地图，不急，较真。
- 真实目标：整站 crawl 出地图 → 跨会话 resume 续爬 → 私网内网 staging 页要能读（cred_defaults 豁免跨会话不保证——考察错误行）。
- 验收：resume 照抄可续；私网行指路（R02-001 回归）；per-call ignore_robots 三态仍各成立（P10b 回归）。
- 耐心：L3 猎手，愿意挖到底并记录 wire 原话。
- 不告诉 AI：resume_token 已过期场景。
- 变卦点：爬到一半改 search 词。
- 主攻：web_crawl(resume/跨会话) + cred_defaults + sys_state + web_read；绑定回归 R01-003/R02-001/P10b 三态。

### P03 蒲国栋 · 咨询顾问 L2
- 情境：客户下午要竞品速览，急。
- 真实目标：批量读 10 个 URL 汇成一页；长报告只读后半段。
- 验收：批量行可逐行引用；offset 续取字数连续；显式 timeout= 不被 learned 压（R02-004 回归）。
- 耐心：单步 >20s 记摩擦；两步不行就砍需求。
- 不告诉 AI：哪 3 个 URL 是故意写错的路径（考察错误行质量）。
- 变卦点：砍到 5 个 URL。
- 主攻：web_read(urls=批量) + web_read(offset/timeout=) + web_research；绑定回归 R02-004。

### P04 麦冬 · 中学教师 L1
- 情境：办公室备课间隙，不急，AI 用得浅。
- 真实目标：「上周让你们存的那个网页，再给我」——跨会话 recall；出错时看它给不给能懂的指引（sys_guide 路径）。
- 验收：一次说错参数能自救；crawl search 空手时 summary 说人话（R01-002 回归）；工具计数 13（R01-009 回归）。
- 耐心：L1，等 10s；报错看不懂就问「那该怎么办」。
- 不告诉 AI：页面在哪个站。
- 变卦点：要求「用中文告诉我结果在哪」。
- 主攻：web_recall（跨会话）+ web_crawl(search=) + sys_guide；绑定回归 R01-002/R01-009。

### P05 霍砚 · 创业者 L3（缺陷猎手）
- 情境：融资材料要竞品动态，急但自己动手能力强。
- 真实目标：discover 出竞品站地图 → crawl 找 API/定价页 → web_request 对本地 echo POST 验证接口形状 → watch 盯竞品页变化（真实跨进程）。
- 验收：地图含断点续爬信息；POST 回执可核对；watch 私网 URL 的 run 错误行带出路（R02-001 回归）。
- 耐心：L3，逐发挑刺。
- 不告诉 AI：watch 目标是私网（考察 add/run 全链）。
- 变卦点：中途要求「只盯价格字段」。
- 主攻：web_discover → web_crawl → web_request → watch(CLI) + sys_state；绑定回归 R02-001。

### P06 骆迦叶 · 政务信息公开 L1
- 情境：单位要归档某公告页，慢网，不急。
- 真实目标：慢站长页分段取全 + 存档格式可用；超纲要求（「帮我把附件也下载打包」）看它怎么拒。
- 验收：offset 续取能到页尾；超纲要求被拒时不甩锅、给出能做的替代；404 行不带误导数字（E10 观察）。
- 耐心：L1，等 30s（政务站慢是常态）。
- 不告诉 AI：目标是死链（404）。
- 变卦点：要求「把整页连图片存下来」。
- 主攻：web_read(offset/大页) + web_search + sys_guide；新区：慢站/404/超纲。

### P07 湛卢 · 金融研究 L2
- 情境：早盘前要信源增量，很急。
- 真实目标：feed_read since 增量盯 3 个源；「3 天前以来」直接说 3d（E8 三现后的真话观察）；来源交叉验证用 web_research。
- 验收：增量行有日期对账；顶层数点名坏源 URL（R01-001 回归）；不带 timeout 首发预算 20s（R01-008 回归）。
- 耐心：>20s 记摩擦；急。
- 不告诉 AI：其中一个 feed 是坏源。
- 变卦点：中途加第 4 个源。
- 主攻：feed_read(since) + web_research + web_read；绑定回归 R01-001/R01-008 + E8 观察项。

### P08 谷雨 · 前端工程师 L2
- 情境：给团队演示工具能不能替代手测，不急，会刁难。
- 真实目标：login→account 登录态链 → checkout 该问就问 → challenge 同链取值 → drag 全形。
- 验收：确认闸该拦就拦；challenge read→fill 现场能对上（R01-006 回归）；drag 第一拒全形（R01-010 回归）。
- 耐心：每步挑措辞。
- 不告诉 AI：checkout 要先确认（看它问不问）。
- 变卦点：演示中途改用 keyboard 提交。
- 主攻：web_act 全动作面 + web_request；绑定回归 R01-006/R01-010。

### P09 迟桉 · 自由翻译 L2
- 情境：接了个 40 页扫描件 + GBK 表格的活，急。
- 真实目标：doc_parse 吃 GBK CSV 与多 sheet；扫描件走 OCR 档；分段对账字数。
- 验收：编码自识、sheet 全出、merged cells 披露（R02 良好行为保持）；遇外网 401/403 墙时杠杆指 cred_defaults（R02-003 回归）。
- 耐心：单文件 >30s 记摩擦。
- 不告诉 AI：其中一个文件是假 PDF（not_a_pdf 具名回归）。
- 变卦点：要求「只翻第二个 sheet」。
- 主攻：doc_parse + web_read + web_research；绑定回归 R02-003 + R02 良好行为组。

### P10 荀羽 · 游戏攻略作者 L1
- 情境：晚上写攻略，随性，常被视频页/跳转页坑。
- 真实目标：搜攻略 → 点开是签名链/视频页（E9 新区）→ 换来源 → 明天同一页二访（跨会话）。
- 验收：特殊页面如实说「这是什么」；跨会话二访有记忆路径可走；放弃点真实记录。
- 耐心：L1，三步不顺就「算了不用了」。
- 不告诉 AI：他要的其实在同一站的文字版。
- 变卦点：中途改搜另一个游戏。
- 主攻：web_search → web_read（特殊页）→（跨会话）web_recall；新区 E9。
