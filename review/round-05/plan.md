## 十张画像卡（封存，执行前不改）

### P01 邵岐 · SRE/值班工程师 · L3（缺陷猎手）
- 情境：凌晨告警，把 dhole 当探针打故障页。
- 真实目标：假域名/死端口/慢站三连——看 all_tiers_failed 的逐层账目与错误族（connect_error vs timeout vs http_error）。
- 验收：每层说了谎没有；预算分账对得上墙钟。
- 不告诉 AI：第二个域名是死端口。
- 变卦点：中途把 timeout 从 5s 改 60s。
- 主攻：web_read（故障三连）+ sys_state；绑定回归 archive 档账目（R02-002）。

### P02 梅疏影 · 内容编辑 · L1
- 情境：截稿前找素材，急。
- 真实目标：搜一个冷门词（引擎会失败几个）→ 读结果 → 失败时看得懂吗。
- 验收：降级池如实（families_answered_of_asked）；失败行说人话。
- 不告诉 AI：词冷门到引擎大概率空手。
- 变卦点：换通俗词重搜。
- 主攻：web_search（降级池）+ web_read + sys_guide；绑定回归 R01-009。

### P03 蔺相宜 · 法务合规 · L2
- 情境：核验一份已下线的监管文件。
- 真实目标：404/410 页走 archive 档（真触发！）——工具描述说 404/410/451 走 Wayback。
- 验收：archive 档真被问到；capture 索引页不再被盖章（R02-002 回归）。
- 不告诉 AI：文件真的已 410。
- 变卦点：要求「只要 2024 年的快照」。
- 主攻：web_read(外网死链) + sys_state；绑定回归 R02-002/R02-003。

### P04 弭兵 · 数据工程师 · L3（缺陷猎手）
- 情境：批量任务里混进坏 URL，看工具的批量语义。
- 真实目标：urls= 批量 8 发混 3 坏（死端口/404/私网）——行级错误族分账；timeout= 显式在批量里的分摊。
- 验收：错误族三样齐全且互不冒充；好行不受坏行拖累。
- 不告诉 AI：哪三发是坏的。
- 变卦点：要求 includes_headers。
- 主攻：web_read(urls=) + sys_state；绑定回归 R02-004（显式 timeout）。

### P05 亢明玉 · 采购 · L2
- 情境：比价页经常被墙。
- 真实目标：被墙站的 force_fetcher=stealthy 语义 + 非法值（force_fetcher='magic'）的拒绝话术。
- 验收：非法参数第一拒就教全合法名单。
- 不告诉 AI：会故意传错参数。
- 变卦点：传未知参数名。
- 主攻：web_read(force_fetcher) + web_request；参数边界区。

### P06 秋原野 · 自由摄影师 · L1
- 情境：给自己的作品页做体检。
- 真实目标：慢图站读图（OCR/媒体档）+ 大 max_content_chars 与负值/零值的边界。
- 验收：边界值被钳制且申报（不是静默改）。

- 变卦点：传 offset=99999。
- 主攻：web_read(边界值) + sys_guide。

### P07 满宠儿 · 财经自媒体 · L2
- 情境：盯三个源，其中一个是坏 RSS。

- 验收：坏源不拖垮好源；错误族各说各的。

- 主攻：feed_read + web_research；绑定回归 R01-001/R01-008、E8。

### P08 傅筛 · 安全研究员 · L3（缺陷猎手）
- 情境：给内网做资产巡检，专打边界。

- 验收：每一族拒绝都说对段名；重定向后的 ssrf_recheck 在场。

- 主攻：web_read(私网谱) + cred_defaults + sys_state；绑定 R03-001/R04-002 澄清。

### P09 宿雨 · 学术编辑 · L1
