<!doctype html><html lang="zh"><head><meta charset="utf-8"><title>本地抓取工具配置指南</title></head><body><h1>本地抓取工具配置指南</h1>
<p>本地抓取工具在默认配置下会把结果写进一个本地缓存库，避免重复请求同一页面。</p>
<p>缓存条目带有过期时间，过期后再次抓取会重新发起请求并覆盖旧条目。</p>
<p>抓取器分成两层：一层是快速 HTTP 层，一层是能执行脚本的反检测浏览器层。</p>
<p>自动升级只在 HTTP 层判定失败时发生，判定依据是状态码、正文长度与反爬特征串。</p>
<p>反爬特征串包括常见的人机校验页面标题，命中后不会重试而是直接升级。</p>
<p>缓存键包含目标地址、会话标识与凭据指纹，因此登录态内容不会与公开内容混放。</p>
<p>关于缓存保留时长：缓存默认保留 3600 秒，改 cache_ttl 可覆盖。</p>
<p>抓取结果的正文会经过抽取器转成 Markdown，超长时按字符数截断并给出续读偏移。</p>
<p>截断点始终落在字符边界上，续读时把偏移量传回来即可拿到剩余部分。</p>
<p>所有网络请求都受 robots 规则约束，除非显式声明调用方已获得站点授权。</p></body></html>
